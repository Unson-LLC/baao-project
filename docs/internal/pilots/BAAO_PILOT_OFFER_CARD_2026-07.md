# BAAO 60日パイロット 提示カード

- 適用期間: 承認後60日または完了5取引の早い方
- 性質: 価格と需要を検証するための仮条件。恒久制度ではない
- 使用条件: 法務確認済みの個別契約・SOWと併用する

## 最初にお伝えすること

今回の案件について、BAAOとの関わり方を4つに分けて選べます。全部を選ぶ必要はありません。どれも選ばないこともできます。

断っても、BAAOの会員資格、称号、案件紹介、イベント参加、今後の相談に不利益はありません。検討中の選択肢を他の選択肢の条件にすることもありません。

## 選択肢

| 選択肢 | 選ぶ場面 | BAAOが出すもの | 相手が出すもの | パイロット条件 |
|---|---|---|---|---|
| Lead / Referral | BAAOが新しい顧客接点を作った | 接点、引継ぎ、紹介記録 | 成約時の紹介料 | GCV 10%、証拠接点から12か月。既存接点には適用しない |
| Delivery / Co-Delivery | 案件開始前からBAAOの監修・PM・品質確認が必要 | SOW記載の役務と責任 | 役務対価 | Standard 60万円。70%前受け、30%検収時 |
| Case | 完了実績を検証・編集・配信したい | Fact-check、Case ID、掲載、標準配信 | 掲載料、素材、公開許諾 | Lite 8.5万円 / Standard 16万円 / Sponsored 43万円 |
| Knowledge | テンプレートや方法論を再利用・販売したい | 商品化、販売、権利管理 | 個別ライセンスと制作 | 固定型96万円前受け / 予約型60万円前受け |
| どれも選ばない | BAAO関与が不要 | なし | なし | 費用なし。会員上の不利益なし |

Lead、Delivery、Case、Knowledgeは別取引、別契約、別同意である。Caseを選ぶ条件としてKnowledge提供を求めない。BAAOの実績表示を条件に、雲孫や会員の直接案件をBAAO契約へ付け替えない。

台帳では条件別に次の`offer_variant`を使う。条件や価格を変えた場合は同じ識別子を流用しない。

| 提示条件 | `offer_variant` |
|---|---|
| Referral 10%・12か月 | `referral_10pct_12m` |
| Co-Delivery Standard 60万円 | `co_delivery_standard_600k` |
| Case Lite 8.5万円 | `case_lite_85k` |
| Case Standard 16万円 | `case_standard_160k` |
| Sponsored Case 43万円 | `case_sponsored_430k` |
| Knowledge固定型96万円 | `knowledge_fixed_960k` |
| Knowledge予約型60万円 | `knowledge_preorder_600k` |

## 初回標準価格

### Lead / Referral

- 料率: GCV 10%。
- 期間: BAAOが作ったことを証明できる最初の接点から12か月。
- 対象外: 既存接点、偶然の社名認知、名刺交換への同席だけ、事後申告。

### Delivery / Co-Delivery

- Standard: 60万円。週次レビュー6〜8回と納品前品質確認。
- 支払: 70%を本体役務開始前、30%を検収時。
- 個別メニュー: 直接原価を見積もり、P10粗利率20%以上となる固定額。
- 表示: BAAOの責任範囲をSOWに書き、契約・実装主体と分けて表示する。

### Case

| メニュー | 価格 | BAAO作業上限 | 納品 |
|---|---:|---:|---|
| Lite | 8.5万円、100%前受け | 3時間 | Fact-check、Case ID、掲載、標準配信 |
| Standard | 16万円、100%前受け | 8時間 | 構成編集、Fact-check、Case ID、掲載、標準配信 |
| Sponsored | 43万円、100%前受け | 編集12時間 | 企画、著者15万円、編集、掲載、標準配信 |

公開には顧客、契約主体、権利者の許諾が必要である。許諾取得前に「BAAO実績」として告知しない。

### Knowledge

| メニュー | 制作開始条件 | 著者対価 |
|---|---|---|
| 固定型 | 販売先から96万円を100%入金 | 40万円＋入金純売上20% |
| 予約型 | 予約前受け合計60万円 | 最低保証30万円を純売上40%へ充当 |

対象権利は、閲覧、案件利用、販売、改変、再許諾、AI学習・RAGを個別に選ぶ。Caseの許諾だけでKnowledge利用を認めたことにはしない。

## スコーピング

見積、権利、顧客許諾、COIを確認する場合は、作業開始前に次のスコーピング料を支払う。

| 対象 | 金額 |
|---|---:|
| Case | 2.3万円 |
| Co-Delivery / Sponsored Case | 3.8万円 |
| Knowledge | 5.3万円 |

- BAAOが作業を始める前にBAAO都合で受付を断る場合は全額返金する。
- 合意したスコーピング作業の開始後は、本体取引が成立しなくても返金しない。
- 本体取引が成立した場合は、本体価格へ全額充当する。
- 追加調査は、追加料金と上限を先に合意する。

```text
[ ] Lead / Referralを検討する
[ ] Delivery / Co-Deliveryを検討する
[ ] Caseを検討する
[ ] Knowledgeを検討する
[ ] 今回はどれも選ばない
[ ] まだ決めない

断っても会員上の不利益がないとの説明を受けた: はい / いいえ
提示の公平感（1: 不公平〜7: 公平）:
気になる条件・断る理由:
```

回答を急がせない。標準では提示から2営業日以上の検討期間を置き、その間に称号、希少枠、他会員の参加状況を使って判断を迫らない。
