# BAAO案件判定票｜標準案件用

- 対象: 新規相談の初期判定
- 所要時間の目安: 5分
- 詳細規程: [`OPERATIONS_HANDBOOK.md`](OPERATIONS_HANDBOOK.md)

この判定票は、日常案件を理事会へ持ち込まずに処理するための入口である。迷った項目だけハンドブックを確認し、例外条件に当たる場合だけ理事合議へ回す。

## 1. 最初の2問

### 問1　誰が顧客と契約し、最終責任を負うか

- BAAOなら「元請」を選ぶ。
- 雲孫、会員、会員法人、その他の事業者なら、その主体の案件として扱う。
- 決まっていなければ停止する。

### 問2　BAAOは具体的に何を提供するか

該当するものだけを選ぶ。該当しなければBAAO取引はなく、BAAOへの対価も発生しない。

| BAAOの関与 | 選ぶもの | 最低限必要な記録 |
|---|---|---|
| BAAOが顧客契約と最終責任を負う | 元請 | 顧客契約、最終責任者、実装者との役務合意 |
| BAAOが証拠のある新規接点を作った | 縁繋ぎ | 接点の証拠、対象売上、料率、期間、支払時点 |
| BAAOが開始前から監修、品質確認、進行管理、編集などを担う | 立合い・伴随 | 開始前の役務合意書、成果物、責任、工数上限、価格 |
| 完了実績を事実確認し、編集、掲載、配信する | 実践録 | 会員状態、提供主体、顧客許諾、事実確認 |
| 方法論、教材、型、データ等を編集、販売、AI利用する | 秘伝許諾 | 権利者、利用範囲、報酬、再許諾、終了条件 |

複数を選ぶ場合は、それぞれの役務、対価、責任、許諾を分ける。実践録への同意を、秘伝許諾への同意として扱わない。

## 2. 標準案件の確認

次がすべて「はい」なら、案件担当者と指名済みの承認者で処理する。

- [ ] 契約主体、提供主体、最終責任者が決まっている。
- [ ] 上の表で必要な関わり方を迷わず選べる。
- [ ] 承認済みの価格、料率、契約ひな型、許諾範囲に収まる。
- [ ] 粗利率20%以上を見込める。
- [ ] 利益相反と未解決の権利問題がない。
- [ ] BAAOの関与を実態以上に表示しない。
- [ ] 断った人が不利益を受けない。

## 3. 理事合議へ回す条件

次のどれかに当たる場合だけ、関係当事者を除く理事の合議へ回す。

- [ ] 関わり方の切り分け、責任、対価について判断が割れる。
- [ ] 標準価格、料率、契約ひな型から外れる。
- [ ] BAAOが初めて扱う役務で元請となる、標準契約を超える責任を負う、または標準外の保証・認定表示を求められる。
- [ ] 理事、案件担当者、関係会社に利益相反がある。
- [ ] 新しい役務、権利利用、表示方法を追加する。

理事合議でも、自力獲得案件への会員税、実態以上の実績表示、許諾の抱き合わせ、辞退への不利益、顧客許諾なしの公開は承認できない。

粗利率20%未満、契約主体または最終責任者が不明、権利・許諾・利益相反を解消できない案件は、理事合議へ回して続行せず停止する。
