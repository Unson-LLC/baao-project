## 1. エグゼクティブサマリー

**結論：現行CBAA制度は「設計図はあるが建物がない」状態であり、このまま実案件に適用すべきではない。**

1. **制度は紙の上にしか存在しない。** CBAA（Co-Branding & Attribution Addendum）の契約テンプレはリポジトリのどこにも存在せず、Handbook自身が「CBAAテンプレを公開し…周知」を未完了チェックリストとして残している（Handbook L214）。審査基準・NSR算定方法・支払起算日・退会後の扱いはすべて未定義。
2. **12%／5%という数字に根拠となる検討記録がない。** 12%/5%は2025-10-05のHandbook初回コミット（佐藤圭吾）から一度も変更されておらず、コミットメッセージ・議事録のどこにも導入検討の痕跡がない。心理設計（努力正当化・名誉との交換）の説明はあるが、経済的な積算根拠は文書化されていない。
3. **BAAOの内部単価と自己矛盾している。** Handbook自身がC案件でBAAOが提供する役務（Case Editorレビュー＋Senior Fellow 30分レビュー＋公開管理）に相当する「ケース監修」をExpert Pool単価5–10万円/件と値付けしている。一方PC拠出はNSR連動で、月額100万円×12か月の案件なら**144万円/年**に達する。提供価値の10〜20倍の徴収であり、「実績を買い取らせている」外観を自ら作っている。
4. **「5%減免」は減免になっていないケースがある。** 5%オプションは現金5%に加えケース執筆＋レシピ執筆の労働を要求する。Handbookは秘伝書執筆に40–60万円を支払う（P案件時）ため、BAAO自身の単価で換算するとNSR約700万円未満の案件では**5%オプションの実質負担が12%現金より重い**。
5. **推奨：売上連動を廃止し、3層に分離する。**
   - **Case Listing（実績掲載）**：固定審査・編集料（ケース＋レシピ現物提供で免除）。表記は「BAAO会員実績」でBAAO受注実績と明確に区別。BAAOは品質保証しない。
   - **Co-Delivery（共同提供）**：BAAOが監修・方法論・QAを有償役務として提供した案件のみ「BAAO共同提供」を名乗れる。料金は役務メニューの固定額。
   - **Prime**：現行どおりBAAO元請け。
6. **移行コストはほぼゼロ。** 公開ケースはサンプル3件のみで、実CBAA契約が存在する形跡はリポジトリ上ない。最初の実案件が発生する前の今が、制度を差し替える唯一の安価なタイミングである。

## 2. 現行制度の正確な復元

以下は**現行文書に書かれている事実のみ**。推測は含まない。行番号はすべて `docs/internal/OPERATIONS_HANDBOOK.md`（以下HB）基準（他ファイルは明記）。

### 2-1. 制度の骨格（P/C/R）

| 項目 | P（Prime） | C（Co-Branded） | R（Referred) |
|---|---|---|---|
| 定義 | BAAO受託の正規（HB L115） | 個人/会員主契約だが「方法・公開・拠出」でBAAO実績に格上げ（HB L116） | 紹介。12か月の紹介権（HB L117） |
| 契約 | クライアント↔BAAO（MSA/SOW、HB L1367） | クライアント↔個人/会員（主契約）＋ BAAO↔個人/会員（CBAA）（HB L1405-1410） | 紹介のみで手を離す（HB L1424） |
| 金銭 | NSR→PF18%→CP分配（HB L88-94） | PC＝NSRの12%現金、または公開ケース＋レシピ1本で5%に減免（審査）（HB L1416-1418, L988-990） | 紹介料GCVの10%、有効期限12か月（HB L1428） |

| 審査 | 秘伝書使用必須・監修SF必須（HB L1159-1169） | 三層タグ適合＋Case Editorレビュー＋Senior Fellow 30分レビュー（HB L1412-1414） | （記載なし） |

## 3. 現行制度が作られた意図

**Git履歴からの機械的事実**（確度：高）：

- CBAA・PC 12%/5%・P/C/R・Influenced Revenueの全設計は、Handbook初回コミット `5e2b564`（2025-10-05、佐藤圭吾、件名「Year 1理事報酬ゼロ設定、黒字化達成（+286万円）」）で**一括導入**された。
- 以後の数値変更はゼロ。2026-01-08の `5fc149d`（koma-ry1117）は用語改称のみで12%/5%に触れていない。
- コミットメッセージ・議事録（`meetings/` 全検索）に共ブランド制度の検討・合意の記録は**存在しない**。

**Handbook本文から読み取れる設計意図**（確度：高、ただし経済根拠ではなく心理設計）：

1. **フリーライド防止と参加誘導**：「C/Rにも正当な居場所を作ることでフリーライド→参加へ誘導」（HB L121-122）
2. **PCの痛みの中和**：「努力正当化と名誉（公開）の交換でPCの痛みを中和」（HB L101-102）——12%は「痛み」であることを設計者自身が前提にしている
3. **実装知の蓄積**：「BAAO＝実装知のデータベース＋インフルエンサー専門家集団」（HB L900-902）。C案件の真の狙いはケース・秘伝書という**組織資産の獲得**
4. **影響力の集団増幅**：会員が「自分の案件をBAAOブランドで出す→影響力増幅→BAAO内地位向上」という循環（HB L917-935）

**評価**：初回コミットの件名が財務シミュレーション（黒字化）であることから、12%/5%は事業計画上の収益仮置きとして一括設計された可能性が高い——ただしこれは推測であり、Handbookに積算根拠の記載はない。確実に言えるのは、**制度の目的は「PC収入」ではなく「実装知の蓄積とブランド増幅」だと設計者自身が書いている**こと。金銭徴収は目的でなく手段であり、手段が目的（知見蓄積）を阻害するなら差し替えに理論上の障害はない。

## 4. 現行制度の問題点

### 4-1. 経済設計の問題

| # | 問題 | 詳細 |
|---|---|---|
| E1 | **獲得非関与への売上連動課金** | BAAOが案件獲得・契約・実行のいずれにも関与しない案件でNSR連動の対価を取る。フランチャイズ（ブランド＋集客＋システム提供）や紹介料（案件供給）と違い、売上への寄与が存在しないため「売上に比例する対価」の理論的根拠がない |
| E2 | **NSRが監査不能** | C案件の会計帳簿はBAAOの外にある。COGS定義（§2-3 #2）がないため、会員が外注費・自社原価を膨らませればNSRは恣意的に圧縮できる。逆に誠実な会員ほど多く払う逆選択構造 |
| E3 | **案件規模比例の不合理** | BAAOの提供役務（レビュー＋公開）は案件規模と無関係にほぼ一定。100万円案件と1億円案件で提供価値は同じなのに徴収額が100倍になる |
| E4 | **内部単価との自己矛盾** | HBはケース監修を5–10万円/件、SF監修（伴随級）を30–50万円と値付け（L1237-1252）。C案件の役務はこれより軽いのに、徴収は数十〜百数十万円 |
| E5 | **「5%減免」の逆転** | §6-3参照。NSR約700万円未満では、BAAO自身の執筆単価（秘伝書40–60万円）で換算した現物拠出＋5%現金が12%現金を上回る |
| E6 | **7ポイント減免の根拠不在** | ケース＋レシピの価値はNSRと無相関なのに、減免額（NSR×7%）はNSRに比例する。大型案件ほど「1本のレシピ」が高く買い取られる計算になり整合しない |
| E7 | **継続・レベシェア案件で破綻** | 月額契約は12か月でPC144万円/年（月額100万円時）、契約が続く限り無期限。レベニューシェア型はNSR確定時点が定義できず算定不能 |

### 4-2. 表示・信頼の問題

| # | 問題 | 詳細 |
|---|---|---|
| T1 | **「実績を買う」外観** | 金銭を払えばBAAOのケース一覧・Yearbookに載る構造。C格付ラベルはあるが、閲覧者が格付定義まで読む保証はなく、優良誤認（景表法上の論点、§20参照）と「実績ロンダリング」批判の両方に脆弱 |
| T2 | **品質保証なき実績表示** | C案件の審査はSenior Fellow「30分」レビューのみ。BAAOは契約当事者でなく品質責任を負わないのに、ブランドは付与する。事故時にBAAOの説明責任だけが残る |
| T3 | **Influenced Revenueの過大計上リスク** | C/DのNSRを「影響売上」として四半期開示（HB L1439）するが、BAAOの寄与が公開レビューのみの案件の売上全額を「influenced」と呼ぶのは、対外的には水増しと受け取られうる |
| T4 | **P:C:R＝5:3:2目標の逆効果** | 公開比率をKPI化（HB L201）すると、比率合わせのためにC案件をかき集める誘因が生まれ、T1を悪化させる |
| T5 | **顧客許諾の空白** | 会員の顧客はBAAOと接点がない。顧客が「知らない団体のサイトに自社事例が載っている」事態が構造的に起こりうる |

### 4-3. 運用・ガバナンスの問題

| # | 問題 | 詳細 |
|---|---|---|
| O1 | **契約実体の不在** | CBAAテンプレなし。現状で実案件に適用すれば口約束運用になる |

### 5-3. ベンチマークからの示唆（8点）

1. **検証できた全プログラムで、会員が自力獲得した役務案件の売上%を共ブランドの対価として徴収する例はゼロ。** 売上連動が存在するのは、ベンダーが決済・流通レールを運営する場面（Marketplace手数料）だけ。
2. **事例掲載は「支払って得る特権」ではなく「昇格要件」または「無償の特典」。** 知見（ケース）の提供自体が対価と見なされる（CNCF型）。BAAOの「ケース提供で12%→5%に減免」は、**業界慣行の逆転**（他所ではケースを出すと地位が上がる。BAAOでは金を払う権利が安くなるだけ）。
3. **団体型組織の標準は「固定・規模バンド制の年会費」**（CNCF/LF/freee/MF/士業ネットワーク）。少人数運営でも監査装置が不要で回る、という運用上の合理性がある。
4. **売上%が正当化されるのは、徴収側が販売力を提供している場合のみ**：フランチャイズ（システム＋集客＋商圏で10–15%）、強いブランドの商標ライセンス（5–15%）、紹介料（案件供給で10–20%）。BAAOのC案件はこのいずれの前提も満たさない（獲得非関与・ブランド価値未証明・システム提供なし）。
5. **12%はフランチャイズ級、5%は確立ブランドの商標ライセンス級の料率**であり、設立1年未満・公開実績ゼロのBAAOブランドに対する対価としては説明が成立しない。
6. **Big4型ネットワークですら中央体は顧客売上を持たず、相互責任を明示的に切断している**（「liable only for their own acts and omissions」）。ブランドを貸す側は責任切断と品質統制をセットで文書化するのが常道。
7. **IESBAの先例**：売上・利益の分配＋共通ブランド＝「一体のネットワーク」認定→連帯的義務、という構造は、BAAOが売上連動PCを続ける場合の「BAAOも当事者だろう」という第三者の期待形成と同型のリスク。
8. **金銭の流れは「プラットフォーム→会員」が多い**（MF紹介報酬、HubSpotコミッション、freeeランク特典）。会員の案件をエコシスタムの成果と見なし、報酬で知見・実績の還流を促す設計が主流。

**適用上の注意**：上記はいずれもBAAOより桁違いに大きい組織の制度であり、料率・金額をそのまま移植すべきではない。ただし本件で借用するのは金額ではなく**構造原理**（固定会費／知見＝対価／役務にのみ課金／責任切断の明文化）であり、これらはむしろ小規模組織ほど運用しやすい。

## 6. 経済合理性の試算

### 6-1. 前提

- BAAOがC案件1件に実際に提供する役務（HB記載の全量）：Case Editorレビュー、Senior Fellow 30分レビュー、公開管理・Yearbook掲載・検証QR発行。

### 6-3. 「5%減免」の実質負担（重要な発見）

5%オプション＝現金5%＋ケース1本＋レシピ1本の執筆労働。BAAO自身がP案件で秘伝書執筆に支払う単価は**40–60万円/本**（HB L1220：秘伝書売上の執筆40%）。ケース執筆分も含め現物拠出を約50万円と置くと：

```
12%現金       = 0.12 × NSR
5%＋現物      = 0.05 × NSR + 約50
損益分岐      : 0.07 × NSR = 50  →  NSR ≒ 714万円
```

**NSR約714万円未満の案件では、BAAOの内部単価で評価する限り「減免」オプションの方が会員の実質負担が重い。** ケース②（NSR300万円）では12%＝36万円に対し、5%＋現物＝15万＋50万＝65万円相当。「減免」という名称自体がミスリーディングである。

### 6-4. 価値と徴収の釣合い評価

| 観点 | 評価 |
|---|---|
| 会員が受け取るもの | C格付ロゴ表示、ケース掲載、Yearbook、SF30分レビュー、Impact Points（+3/+2） |
| 同等物のBAAO市場価格 | ケース監修5–10万円（HB L1250）。BAAOブランドの外部market valueは未証明（設立2025Q4、公開実績はサンプルのみ） |
| ケース②での支払 | 36万円（対価の3.6〜7倍） |
| ケース④での支払 | 144万円/年（対価の10〜20倍） |
| 結論 | **提供価値と徴収額は釣り合っていない。** 小型案件（①）ではBAAO側が原価割れし、中大型では会員側が一方的に過払いになる。どの規模でも「ちょうど良い」点が存在しないのは、対価が役務でなく売上に連動しているため |

### 6-5. 制度を利用しない場合との比較（会員視点）

ケース②の会員がCBAAを使わない場合：36万円を節約し、自社サイトに自社実績として掲載できる（顧客許諾は自分で取る）。失うのはC格付表示とImpact Points+5のみ。**現行制度は「合理的な会員ほど使わない」設計**であり、これはHBが自認する目的（フリーライド→参加への誘導、L121-122）と正反対に作用する。

| 不正利用の防止 | NSR過少申告を防げない | 売上非連動のため申告不正の動機自体が消滅 | 同左＋役務は実施記録で検証可能 |
| 主なメリット | 変更最小 | 単純・即日運用可 | 誤認防止と収益化を両立、原則1〜12全充足 |
| 主なデメリット | 根本問題（E1–E7）が残存 | BAAOの関与実績（Influenced）を作る経路がない | 制度が2枚になる（ただし各々は単純） |

**判定：F案を推奨。** A案は「BAAOが提供した価値に対してのみ対価を得る」（判断原則1）を満たせない。B案は単独では共同提供のニーズ（品質担保つきの案件をBAAOブランドで出したい会員）を取りこぼす。F案はBをCase Listing層として内包する。

## 8. 推奨制度（3層モデル）

ユーザー設問の「Case Listing / Co-Delivery / Prime の3段階が現行P/C/Rより適切か」への回答：**適切である。ただし紹介（R）は「格付」から外し、金銭制度（紹介料）としてのみ残す。**

### 8-1. 全体像

```
┌─────────────────────────────────────────────────────────┐
│ Prime（BAAO元請け）                                       │
│  契約・品質・PM責任＝BAAO。Recognized Revenue。            │
│  表記「BAAO実績」。現行P評価を無変更で継続。               │
├─────────────────────────────────────────────────────────┤
│ Co-Delivery（共同提供）                                   │
│  契約＝会員。BAAOが監修/方法論/QA/PM支援を有償役務提供。   │
│  表記「BAAO共同提供（担当分担を明記）」。                  │
│  Influenced Revenue（新定義§11）に計上。                  │
├─────────────────────────────────────────────────────────┤
│ Case Listing（会員実績掲載）                              │
│  契約・実行・責任＝会員。BAAOは編集・審査・掲載のみ。       │
│  表記「BAAO会員による実績（BAAO受注ではない）」。          │
│  売上集計に一切入れない（件数のみ開示）。                  │
└─────────────────────────────────────────────────────────┘
   （別枠）Referral：紹介料 GCV10%・12か月。格付ではなく
   金銭制度。紹介案件の掲載はListing/Co-Deliveryの要件を
   満たす場合のみ。
```

### 8-2. Case Listing（会員実績掲載）

- **対象**：会員が自力獲得・自社契約・自社実行した案件。BAAOは獲得に関与していなくてよい（それが前提）
- **利用条件**：
  1. 顧客の書面公開許諾（匿名化レベル含む、§13の書式）
  2. 三層タグ（Field×Mission×Practice）適合
  3. Case Editorのファクトチェック（KPI数値はエビデンス添付：ダッシュボード画像・測定ログ等。提出不能なら数値をレンジ・定性表現に落とす）
- **対価（いずれか）**：
  - **現物**：公開ケース1本＋レシピ1本の提供 → **掲載料無料**（これを標準経路とする）
  - **現金**：ケースのみ提供の場合、審査・編集料 **5万円/件（固定）**
- **BAAOが提供するもの**：編集・掲載・検証QR・Yearbook掲載。**品質保証・成果保証はしない**（掲載同意書に明記）
- **BAAOが提供しないもの**：ブランドによる受注保証、営業支援、契約関与
- **狙い**：判断原則6（実装知の蓄積）を最優先し、金銭障壁を実質ゼロにして知見が集まる方向にインセンティブを倒す

### 8-3. Co-Delivery（共同提供）

- **対象**：会員契約の案件に、BAAOが**業務開始前から**役務で関与するもの（事後の「鞍替え」は不可——これが現行C評価との決定的な違い）
- **役務メニューと固定料金**（§9）：監修パック、方法論ライセンス（秘伝書利用権）、品質検証、PM支援
- **表記**：「Co-Delivered with BAAO」＋担当分担の明記（契約：会員法人／実装：会員法人／監修：BAAO Senior Fellow ○○）
- **品質責任**：BAAOは**提供した役務の範囲で**専門家責任を負う（監修した設計の妥当性等）。案件全体の契約責任は負わない
- **Influenced Revenue**：この層のみ案件GCVを「BAAO関与案件総額」として集計してよい（§11）

### 8-4. Prime

現行どおり。変更なし（分配式・秘伝書必須・監修必須は本レポートのスコープ外）。

### 8-5. 判断原則との照合

| 原則 | 充足 |
|---|---|
| 1 提供価値のみに対価 | ○ 掲載＝編集実費、共同提供＝役務単価 |
| 2 獲得者の経済を奪わない | ○ 売上連動を全廃 |
| 3 名義貸ししない | ○ 役務なき案件は「会員実績」としか表記させない |
| 4 誤認させない | ○ 3層で表記を分離（§12） |
| 5 責任主体の明示 | ○ 担当分担の明記を掲載要件化 |
| 6 知見の組織資産化 | ○ 現物提供（ケース＋レシピ）を無料経路として最優先 |
| 7 属人化しない | ○ チェックリスト審査＋固定料金（裁量排除） |
| 8 審査コスト＜制度価値 | ○ 掲載審査2–4h、対価は現物または5万円 |
| 9 小規模でも運用可 | ○ NSR監査が不要になったため |
| 10 契約と許諾を事前に | ○ Co-Deliveryは事前関与必須、Listingは許諾書必須 |
| 11 再現可能なルール | ○ 判定は書面要件のみ |
| 12 売上と影響の分離 | ○ §11の新定義 |

## 9. 推奨する料金体系

**既存の5%/12%は維持しない。** 数値はすべてHandbook既存の内部単価（Expert Pool）から積算した提案値。

### 9-1. Case Listing

| ケースのみ（レシピなし） | **5万円/件** | Case Editor編集2–4h＋SF確認30分＋掲載事務の実費（HBのケース監修単価5–10万円の下限） |
| 再審査（差し戻し後） | 無料1回、以降2万円/回 | 乱投稿の抑止 |

### 9-2. Co-Delivery 役務メニュー

| メニュー | 内容 | 料金（会員価格） | 根拠 |
|---|---|---|---|
| ライトレビュー | SF設計レビュー2回＋書面所見 | **10万円** | CONSULT監修3–8万円（HB L1239）＋マージン |
| 監修パック（標準） | 週次レビュー×6–8回＋品質検証＋ケース化支援 | **50万円** | 伴随監修原価30–50万円（HB L1239）＋PF相当 |

| 品質検証（納品前） | チェックリスト検証＋検証レポート | **15万円** | SF稼働1–2日 |

- 支払：着手50%／完了50%。
- 会員区分（PRIME会員等）による2割引は既存の割引体系と整合させてよい。

### 9-3. Referral（変更最小）

- 紹介料 GCVの10%・12か月は外部相場レンジ内（§5参照）のため**料率は維持**。
- 追加要件：紹介の証跡（初回接点の記録）を必須化し、紹介二重率監査（HB L175既存）と接続。

## 10. P/C/Rの維持・変更・廃止の判断

| 格付 | 判断 | 理由 |
|---|---|---|
| **P（Prime）** | **維持** | 定義明確・契約実体あり。ただし用語衝突解消のため対外表記を「BAAO Prime（BAAO受注）」に統一し、プログラム名PRIME（旧評議会）側の改称を検討（§21質問4） |
| **C（Co-Branded）** | **廃止し、2つに分割** | 「事後鞍替え＋売上連動」の現行Cは§4の問題群の根源。**CD（Co-Delivered：事前役務関与）**と**L（Listed：会員実績掲載）**に分割 |
| **R（Referred）** | **格付としては廃止、金銭制度として維持** | 「紹介しただけ」の案件をBAAOのケース一覧に並べること自体が誤認リスク（BAAOは品質に一切関与していない）。紹介料制度は残し、紹介案件の掲載はL/CDの要件を満たす場合のみ |
| P:C:R＝5:3:2のKPI | **廃止** | 比率目標はラベル操作（Re-label）の動機になる。代替KPI：ケース公開本数、レシピ蓄積本数、CD役務売上 |

新格付：**P / CD / L**（＋内部管理上のR＝紹介料台帳）。

## 11. Recognized RevenueとInfluenced Revenueの新定義

| 区分 | 現行定義（HB L1434-1440） | **新定義（提案）** |
|---|---|---|
| Recognized Revenue | 会計売上：A/B（Prime・再販）のみ | **変更なし**：BAAOが契約当事者である売上（Prime＋再販＋掲載料・役務料・紹介料収入） |
| Influenced Revenue | 影響売上：C/DのNSRを四半期開示 | **「BAAO Co-Delivered案件総額」に改称・限定**：BAAOが有償役務を提供したCD案件の顧客契約額（GCV）合計。会員の申告ではなく**役務SOWに紐づく案件のみ**計上 |
| （新設）Member Cases | — | **金額を集計しない。** 公開件数のみ開示（「会員実績 掲載○件」）。L案件の売上をいかなる名目でもBAAOの数字に合算しない |

**理由**：現行のInfluenced Revenueは「30分レビューしただけの案件のNSR全額」を含み得る。対外開示した場合、影響力の水増しと批判されるリスク（§4 T3）が、得られる見栄えの価値を上回る。

## 12. 実績の表記ルールと表示例

### 12-1. ルール

1. すべてのケースカード・Yearbook・SNS発信で、**格付ラベル＋契約主体＋BAAOの役割**を1行で明記する。
2. L案件では「BAAO」を主語にした成果表現を禁止（「BAAOが削減した」→不可。「会員○○社が削減した」→可）。
3. 会員側が自社サイトに同一案件を掲載する場合、BAAO側掲載との矛盾禁止（数値・役割分担は同一表現）。会員側が「BAAO」に言及する場合は所定文言（下記）のみ。
4. 退会・失効後の表記は§16。

### 12-2. 表示例

**Prime（P）**
> 【BAAO受注】検査レポート自動化で P95リードタイム −38%
> 契約・提供：一般社団法人ビジネスAI推進機構（BAAO）／実装：株式会社○○（BAAO実装パートナー）

**Co-Delivered（CD）**
> 【BAAO共同提供】申請書類の要件照合で職員工数 −15%
> 契約・実装：株式会社△△（BAAO Fellow □□）／監修：BAAO Senior Fellow ◇◇（設計レビュー・品質検証）

**Listed（L）**
> 【会員実績】問い合わせ要約で一次解決率 +9pt
> 契約・実装：株式会社△△（BAAO Fellow □□による実績）
> ※本件はBAAOの受注・提供案件ではありません。BAAOはケース内容の編集・検証のみ行っています。

**会員側サイトでの言及可能文言（L案件）**
> 「本事例は BAAO 実戦AI道場の公開ケース（CaseID: FW-XXXX-####）として掲載されています。」
> （「BAAOと共同で実施」「BAAO案件」等の表現は不可）

## 13. 顧客許諾・知的財産・データ利用のルール

### 13-1. 顧客許諾（掲載の前提条件）

- **書式**：「事例公開許諾書」1枚（新規テンプレ、§18で作成指示）。記載事項：公開範囲（実名／業界名＋レンジ／完全匿名）、公開媒体（BAAOサイト・Yearbook・登壇資料）、数値公開の可否、撤回条項（顧客はいつでも撤回可、撤回後30日以内に削除）。
- **取得責任**：会員（顧客との契約当事者）。BAAOはコピー保管のみ。
- **タイミング**：掲載審査申請時に添付必須。許諾なき申請は受理しない。

### 13-2. 知的財産

| 対象 | 帰属・許諾（提案） |
|---|---|
| ケース原稿 | 著作権は会員（執筆者）に留保。BAAOへ非独占・無期限・無償の掲載/翻案許諾（退会後の扱いは§16） |
| レシピ（秘伝書化されるもの） | 会員がBAAOへ**非独占ライセンス**。BAAOが秘伝書として販売する場合、**執筆者取り分40%**（HB L1220のP案件執筆分配と同率）を会員に支払う——現行制度はここが無償化されており不公平 |
| プロンプト・コード | ケース/レシピへの掲載範囲のみ許諾。原本の権利は会員（と顧客契約）に従う |
| 顧客データ・機密 | ケース/レシピに顧客の秘密情報を含めない義務は会員側。BAAOのファクトチェックはNDA下で実施 |
| AI学習利用 | ケース/レシピをBAAOがAIツール（検索・生成）に投入する場合は許諾書に明記しオプトイン。顧客名を含むデータの学習利用は不可 |

### 13-3. データ・秘密保持

- 会員→BAAOのエビデンス提出（KPIログ等）は掲載審査目的に限定、審査後90日で破棄（HBの録画90日保持ルールL1739と整合）。
- 個人情報を含むエビデンスは受領しない（マスキング必須）。

## 14. 審査フローとRACI

### 14-1. Case Listing 審査フロー（標準リードタイム：10営業日）

```
1. 会員申請（申請フォーム＋顧客許諾書＋KPIエビデンス＋三層タグ）
2. 形式チェック（事務局、2営業日）……書類完備・タグ適合
3. 内容審査（Case Editor、5営業日）……ファクトチェック、数値エビデンス照合、
   匿名化処理、表記ルール適合
4. 専門レビュー（該当Field Senior Fellow、30分）……技術的妥当性の確認
   ※判定は「掲載可／数値をレンジ化して掲載可／掲載不可」の3値のみ
5. 公開（CaseID採番・検証QR・Byline確定）＋レシピ受領確認（無料経路の場合）
```

### 14-2. Co-Delivery 開始フロー

```
1. 会員が案件開始前に申請（案件概要＋希望役務メニュー）
2. Field Director が役務SOWを見積・締結（固定額）
3. 役務実施（実施記録＝監査証跡）
4. 完了時にCD格付でケース化（Listing審査フローに合流）
```

### 14-3. RACI

| 活動 | A | R | C | I |
|---|---|---|---|---|
| Listing審査・掲載 | Program GM | Case Editor | 該当Field Senior Fellow | 理事会（四半期報告） |
| Co-Delivery役務SOW | 該当Field Director | 同左 | Senior Fellow | Program GM |
| 料金・制度改定 | 理事会 | Program GM | Case Editor | 全会員 |
| 掲載取下げ・違反措置 | Program GM | 事務局 | 理事会 | 当該会員 |

**属人化対策**（判断原則7）：審査はチェックリスト化し（§18で作成指示）、Case Editor不在時はSenior Fellowが代行可。裁量判断（グレー案件）は月次でまとめてProgram GM裁定とし、裁定結果をチェックリストに追記して次回から機械判定に落とす。

## 15. アンチゲーミングと監査

売上連動を廃止した時点で、最大の不正動機（NSR過少申告）は**構造的に消滅**する。残るリスクと対策：

| リスク | 対策 |
|---|---|
| KPI数値の誇張（実績ロンダリング） | エビデンス添付必須。提出不能な数値はレンジ・定性に降格。虚偽発覚時はAppointment失効＋掲載全抹消＋公表（HB L1899-1906の既存制裁を準用） |
| 同一案件の重複申請（複数会員） | CaseIDと顧客識別子（ハッシュ）で照合。共同案件はByline連名1件のみ |
| L案件を「BAAO共同」と対外詐称 | 会員側言及文言の限定（§12-2）＋年1回のサンプリング（会員サイト・SNSの表記チェック、10件抽出） |
| Co-Delivery役務の形骸化（名目監修） | 役務実施記録（レビュー議事メモ）を成果物に含め、CD格付の要件とする |
| 掲載数稼ぎの低品質ケース量産 | 再審査有料化（§9-1）＋Case Editorの掲載不可判定に理由開示義務なし |
| 紹介の二重申告 | 既存の紹介二重率監査（HB L175）を維持 |

**監査**：四半期監査（HB L1888-1894の既存枠組み）に「L/CD格付の適正」「表記ルール遵守」「役務実施記録の実在」を追加。Re-label率（L→CD→P）の計測は現行のC→P監視（HB L167）を引き継ぐ。

## 16. 契約終了・退会・事故発生時の扱い

現行文書に規定なし（§2-3 #10）。以下を新設する。

| 事象 | BAAO側の掲載 | 会員側の表示 |
|---|---|---|
| 会員の退会・資格失効（円満） | 掲載継続可（事実の記録のため）。ただしBylineに「（在籍当時）」を付記 | 「BAAO掲載ケース」への言及は掲載が続く限り可。「BAAO会員」の現在形表記は不可 |
| 除名・違反による失効 | 当該会員の全ケースを非公開化（30日以内）。Yearbookは版の性質上遡及削除しないが、次版に訂正掲載 | すべてのBAAO言及を90日以内に削除する義務（掲載同意書に明記） |
| 顧客の許諾撤回 | 30日以内に削除（§13-1） | 同時削除義務 |
| 品質事故・炎上（L案件） | 掲載を即時一時非公開→事実確認。BAAOは声明で「本件はBAAOの受注・提供案件ではない」ことを表記ルールどおり説明できる（この防御線こそL/CD分離の価値） | 会員が一次責任。BAAOへの言及自粛 |
| 品質事故（CD案件） | BAAOは監修役務の範囲で説明責任を負う。役務SOWに責任上限（受領役務対価額を上限とする賠償上限条項）を必須記載 | 契約責任は会員 |
| BAAO側の制度廃止 | 既掲載分は表記を維持したままアーカイブ | 既得の言及権は維持 |

```
中途終了    ：会員都合＝実施済役務分精算／BAAO都合＝未実施分全額返金
条件        ：案件の業務開始前（または開始後30日以内）の締結に限る。
             完了済み案件の遡及CD化は不可
```
