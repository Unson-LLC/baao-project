# BAAO制度 あるべき姿への移行実行レポート

- 実行日: 2026-07-17
- 対象ブランチ: `codex/baao-stakeholder-simulation`
- ステータス: 制度構造と新規適用凍結は現行化。対外有償パイロットは未開始
- 現行正本: [`OPERATIONS_HANDBOOK.md`](OPERATIONS_HANDBOOK.md)

## 1. 実行結果

旧制度の一部修正ではなく、Strategic Objective、General Operating Principles、Working Proceduresを持つHandbook v3へ現行正本を置換した。

中心思想は次で統一した。

> 寄与した分だけ名乗り、受け取った価値には返し、断る自由を守る。

現行制度はPrime、Referral、Co-Delivery、Case Verification / Distribution、Knowledge Asset Licenseを別取引として扱う。Case掲載とKnowledge利用、会員資格と案件取引、実績表示と売上帰属を束ねない。

## 2. 変更した運用面

| 面 | 実行内容 |
|---|---|
| 制度正本 | 旧Handbookをアーカイブし、v3を唯一の現行正本にした |
| 旧制度 | 自力案件への売上連動負担、公開格付、影響売上合算、貢献点・失効・自動昇降格を新規凍結した |
| 人事 | Peopleを責任境界、任命証跡、審査ルーブリック、Activity Ledgerへ置換した |
| Governance | 個別Opt-in、権利分離、COI、代替承認、停止条件を現行化した |
| 経済性 | 全有償取引に案件別粗利率20%以上、前受け、原価記録、例外停止を要求した |
| Case | BAAO受注、BAAO共同提供、BAAO会員による実績を分け、紹介を品質格付から外した |
| 公開Web | 未検証の人物、役職、成果数値、ケース、ランキング表示を外し、再検証中表示へ切り替えた |
| テンプレート | Wireframe、Case、案件、評議会、レシピ、講演テンプレートを新制度へ整合させた |
| 再発防止 | 現行ファイルと公開ソースから旧制度語を検出する自動ガードを追加した |

## 3. 検証結果

- 制度SSOT・旧制度語ガード: 3件合格。
- パイロット採算・同意・前受けガード: 9件合格。
- 公開ページ・問い合わせ導線テスト: 13件合格。
- Next.js本番ビルド: webpackで合格。
- `git diff --check`: 合格。

依存関係のインストール時点で既存パッケージに13件の監査警告が表示された。今回の制度移行では依存バージョンを変更していないため、別のセキュリティ対応として扱う。

## 4. 証拠境界

同日取得済みのGraph SSOTとBrainbase Philosophy Contextを制度判断の前提にした。本実行中のライブGraph再取得は`bb.unson.jp`のDNS解決失敗で完了していない。接続失敗をentity不存在とは解釈せず、人物プロフィールとGraph decisionの新規登録は保留した。

公開プロフィール、役職、ケースは、Graph SSOT、一次資料、本人・顧客・権利者の許諾が揃ったものから復帰させる。

## 5. 未完了ゲート

次が揃うまで対外の有償パイロットを開始しない。

1. 最終承認者、パイロットOwner、採算判定者、COI代替承認者の指名。
2. 契約、会員規約、定款、表示、知財、個人情報の法務確認。
3. 入金、返金、報酬、ロイヤリティの会計・税務確認。
4. Activity Ledgerと取引台帳の保存先、閲覧権限、監査方法の決定。
5. CaseとKnowledgeを分離した許諾フォームの承認。
6. 仮価格、工数上限、受付上限の承認。
7. Graphへの制度decision登録。

未完了は需要0件・実績0件を意味せず、実施準備または確認が完了していない状態を意味する。

## 6. 次回の実行順

1. 権限者とCOI代替承認者を任命する。
2. 法務・会計確認を完了する。
3. 台帳と許諾フォームを実装する。
4. 外部公開前にGraph・本人・顧客の三点確認を行う。
5. 上限付き60日パイロットを開始し、受諾率、辞退理由、実工数、粗利、許諾率、公平感を実測する。
6. 実測値だけで恒久価格と役職制度を改定する。
