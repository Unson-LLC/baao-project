## Northstar Story

### id
`northstar.baao.ai-community-flywheel`

### horizon
`northstar`

### view
`business`

### story
BAAOとして、コミュニティ起点のAI導入フライホイールを日本で確立したい。
そうすることで、研修・実装・成果保証を一気通貫で提供し、日本のビジネスAI活用水準を底上げしたい。

### criteria
- [ ] BAAOが「AI研修→コミュニティ→実装（Unson）」の一気通貫ブランドとして認知される
- [ ] 実戦AI道場が企業研修・Unson案件への主要リードチャネルとして機能している
- [ ] 月次MQL（有望リード）がDojoから安定的に発生している

### commit
- [ ] 実戦AI道場の会員数が安定成長している（月次新規20名以上）
- [ ] 道場参加者からの研修・Unsonハンドオフ率が月次追跡されている
- [ ] BAAOのブランドポジションが「中小企業向けAI導入の最速経路」として定義されている

### signal
- [ ] Dojoライブ参加者の自社AI活用実績事例が月1件以上発生する
- [ ] 研修→Unson案件への転換が四半期1件以上続く

### enemy
- 大手コンサルの高価格帯に価格競争で引きずられること
- Dojoをイベント消費で終わらせ、研修・実装につながるリード化が起きないこと
- 山本代表個人の権威性に依存した属人スカウトモデルから抜け出せないこと

### non_goal
- テクノロジー実装（Unsonが担う）
- 大企業向け大規模研修の直接受注

## Quarter Story 1

### id
`quarter.baao.dojo-lead-conversion`

### horizon
`quarter`

### view
`business`

### story
BAAO事業チームとして、実戦AI道場の参加者を今四半期中に研修・Unson案件へ3件転換したい。
そうすることで、Dojoが費用センターではなく収益チャネルとして機能することを証明したい。

### criteria
- [ ] Dojoからの研修・Unson案件転換が今四半期3件以上達成される
- [ ] 転換した案件の成約前受け率が50%以上になる
- [ ] MQL基準（課題ヒアリング完了）が定義・運用されている

### commit
- [ ] 今四半期の週次ライブ開催率90%以上
- [ ] 会員1人ひとりの課題ヒアリング実施件数が月次トラッキングされている
- [ ] 転換ファネル（Dojo参加→ヒアリング→提案→成約）が可視化されている

### signal
- [ ] 今四半期内に研修・Unson案件を3件以上受注する
- [ ] Dojoメンバーが「ここで相談して良かった」と発言するケースが増える

### enemy
- ライブ開催に力を注ぎ、参加者の課題ヒアリングが後回しになること
- 案件転換を「山本代表頼み」にして再現性がない状態のままにすること

### non_goal
- 新規メンバー獲得施策（別の活動）
- 実装フェーズへの介入（Unson担当）

## Quarter Story 2

### id
`quarter.baao.dojo-member-ai-skill-up`

### horizon
`quarter`

### view
`user`

### story
Dojoメンバー（事業責任者）として、今四半期中にAIを使って自社の業務を1つ自動化したい。
そうすることで、AI活用が「勉強」ではなく「実戦で使える武器」だと実感したい。

### criteria
- [ ] メンバーが今四半期内に自社業務への適用を1件以上試みる
- [ ] 適用事例をDojo内でシェアできるフォーマットが用意されている
- [ ] MyWaが適用のエントリーポイントとして使われている

### commit
- [ ] 各ライブに「今週試すこと」のセクションがある
- [ ] Slackコミュニティに適用事例をシェアするチャンネルがある
- [ ] MyWaへのオンボーディングが30分以内で完了する

### signal
- [ ] Dojoメンバーが自社の業務適用事例をSlackでシェアする件数が週1件以上
- [ ] 「MyWaを使ってみた」という発言がライブチャットで毎回出る

### enemy
- ライブが「学び」で終わり、「やってみた」に進まないこと
- 事例シェアの心理的ハードルが高く、メンバーが沈黙すること

### non_goal
- 大規模システム導入支援
- 非Dojoメンバーへのサポート

## Month Story 1

### id
`month.baao.weekly-live-action`

### horizon
`month`

### view
`user`

### story
Dojoメンバーとして、今月のライブに参加してMyWaを使ったAI実践を1回体験したい。
そうすることで、「自分でもできる」という感覚を持ち帰りたい。

### criteria
- [ ] 今月のライブに参加できる（日時を事前に把握している）
- [ ] ライブ中にMyWaのハンズオンセクションがある
- [ ] ライブ後30分以内に「今週試すこと」を1つ決められる

### commit
- [ ] 月次ライブが4回開催される
- [ ] 各ライブにMyWa実践パートが15分以上確保される
- [ ] 参加者が「次のアクション」をライブ後すぐに記録できる仕組みがある

### signal
- [ ] ライブ後アンケートの「今週試すことを決めた」率が70%以上
- [ ] 翌週Slackに実践報告が上がってくる

### enemy
- ライブが講義形式で一方通行になり、参加者が受け身になること
- ハンズオンのハードルが高く、ライブ中に試せないこと

### non_goal
- ライブ録画の完成度
- 非会員向け公開コンテンツ

## Month Story 2

### id
`month.baao.mywa-stable-onboarding`

### horizon
`month`

### view
`dev`

### story
Dojoコミュニティ基盤（MyWa）の開発チームとして、今月中にメンバーのオンボーディング完了率を90%以上にしたい。
そうすることで、ライブ参加者が「使えなかった」という理由でAI実践の機会を損失しないようにしたい。

### criteria
- [ ] 新規会員が7日以内にMyWaを使った最初のAIタスクを完了する率が90%以上
- [ ] オンボーディング失敗のボトルネックが月次で計測・改善されている

### commit
- [ ] オンボーディングフローが3ステップ以内に簡略化される
- [ ] ライブ前日にMyWaへのアクセス確認リマインダーが送られる
- [ ] エラー発生時のサポート導線が明確になっている

### signal
- [ ] 「MyWaが使えなかった」というサポート問い合わせが月5件未満になる
- [ ] ライブ参加者のMyWaアクティブ率が前月比で向上する

### enemy
- 新機能追加を優先してオンボーディング改善が後回しになること
- ハードル調査をせずに「使い方がわからない」ユーザーを放置すること

### non_goal
- MyWaの新機能開発
- 非会員向けの機能
