# Cases & Knowledge Assets｜公開基準

- ステータス: 現行
- 制度正本: [`../internal/OPERATIONS_HANDBOOK.md`](../internal/OPERATIONS_HANDBOOK.md)
- 更新日: 2026-07-17

このディレクトリには、契約主体、提供主体、BAAOの役割、成果根拠、顧客・権利者の許諾を確認できたケースだけを置く。

## 表示区分

| 表示 | 条件 |
|---|---|
| BAAO受注 | BAAOが顧客との契約主体となり、成果・請求責任を負う |
| BAAO共同提供 | 案件開始前SOWにBAAOの有償役務、成果物、責任がある |
| BAAO会員による実績 | 会員・会員法人が提供した実績。BAAO受注・共同提供・品質保証を意味しない |

紹介はLead取引であり、ケースの品質格付ではない。Case掲載は元案件の売上帰属を変えない。

## 公開ゲート

1. Graph SSOTで人物、組織、会員状態、役職、権限を確認する。
2. 契約主体、提供主体、本人の役割を一次資料で確認する。
3. Before / After、測定方法、比較期間、除外条件を確認する。
4. 企業名、個人名、ロゴ、数値、成果物、媒体、期間の許諾を個別に取る。
5. Case掲載とKnowledge・AI利用の許諾を分ける。
6. 公開責任者が表示区分と第三者誤認の有無を承認する。

一つでも未確認なら公開しない。確認できない状態を実績0件とは解釈しない。

## Case記録の最小項目

- Case ID、公開日、更新日。
- Contracting Entity、Delivery Entity、BAAO Role。
- 顧客課題、期間、実施内容、成果物。
- KPIの定義、データ出所、測定方法、比較期間、除外条件。
- 氏名・社名・ロゴ・数値・成果物ごとの許諾状態。
- Case Editor、公開責任者、COI確認。
- 撤回期限、修正履歴、問い合わせ先。

## Knowledge Asset

レシピ、教材、テンプレート、データセット、AI/RAG利用はCaseから自動取得しない。著者・権利者、編集、配信、販売、AI利用、再許諾、対価、撤回方法を別契約で記録する。

現時点の公開ケースは再検証中であり、サンプル人物・成果数値・格付は掲載しない。
