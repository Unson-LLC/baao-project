# ガバナンス・ポリシー｜Governance

- 更新日: 2026-07-17
- 現行運用正本: [`../internal/OPERATIONS_HANDBOOK.md`](../internal/OPERATIONS_HANDBOOK.md)
- 旧版: [`archive/GOVERNANCE_POLICY_V1_LEGACY.md`](archive/GOVERNANCE_POLICY_V1_LEGACY.md)

BAAOは、実装知の検証、品質、流通を担う。権威や所属を使って会員の成果を取り込まず、実際に寄与した範囲だけを名乗り、受け取った価値には対価・流通・機会・帰属を返す。

## 基本原則

- 契約主体、提供主体、最終責任者を先に明らかにする。
- 会員の自力獲得案件を、会員資格だけでBAAO案件へ変えない。
- BAAOの対価は、紹介、監修、編集、配信、知識利用など具体的役務へ対応させる。
- Case、Knowledge、共同提供は個別Opt-inとし、断っても不利益を与えない。
- 権限、責任、COI、許諾、採算を証跡化する。
- 未確認情報をゼロ、否定、承認済みとして扱わない。

## 公開・守秘

実践知の公開は、次が揃った場合に限る。

1. 契約主体と提供者が確認できる。
2. 成果数値と測定方法を事実確認できる。
3. 顧客、著者、権利者が公開範囲へ同意している。
4. 企業名、個人名、ロゴ、数値、成果物、配信、編集、商用利用、AI利用、再許諾を別々に記録している。
5. BAAOの役割と、BAAOが保証しない範囲を明示している。
6. COIを必要な範囲で開示している。

守秘レベルは完全非公開、匿名、要素分解、実名公開から選ぶ。曖昧な許諾は不許諾として扱い、口頭合意だけで公開しない。会合で共有された情報の二次利用も、Chatham House Ruleだけに依存せず、契約・規約・個別合意を確認する。

## COI（利益相反）

判断に影響し得る次の事項を、必要最小限の範囲で開示する。

- BAAOにおける役割と権限。
- 当該案件の契約、提供、紹介、採算、公開への関与。
- 他の会員・組織との取引、出資、雇用、顧問、紹介関係。
- 外部の所属、報酬、株式など当該判断に関連する金銭的利害。
- 当該案件に関与する家族・近親者との関係。

COIがある人は提案や情報提供をできるが、単独で最終承認しない。代替承認者がいない場合は判断を停止する。開示された個人情報は目的外利用せず、閲覧者を限定する。

## 権限と責任

| 判断 | 必要な責任 |
|---|---|
| 契約主体・取引分類 | 案件Ownerが起案し、権限を持つ制度責任者が承認 |
| 価格・採算 | 採算判定者が検証し、受益者と異なる承認者が承認 |
| 共同提供表示 | 開始前SOWと提供証跡を公開責任者が確認 |
| Case公開 | 顧客、提供主体、Case Editor、公開責任者が確認 |
| Knowledge利用 | 著者、権利者、顧客、権利承認者が範囲を確認 |
| 役職任命 | 任命権者が審査根拠、任期、権限、COIを記録 |

最終承認者が不明、またはGraph SSOTで権限を確認できない判断は進めない。

## 会員・役職

役職は人気、件数、売上、無償貢献の競争ではなく、委任された責任を表す。Activity Ledgerは活動の証跡であり、点数表ではない。

- 年次点数、ランキング、自動昇格、自動降格は用いない。
- 活動件数が少ないことだけで資格を失効させない。
- CaseやKnowledgeへの協力を任命・更新・案件配分の条件にしない。
- 審査は専門品質、再現性、信頼性、倫理、協働、検証済み成果を根拠にする。
- 審査理由、承認者、任期、異議申立てを記録する。

詳細は [`../people/README.md`](../people/README.md) を参照する。

## 禁止事項

- 虚偽・誇張・無許諾の成果公開。
- BAAOの関与を実態以上に表示すること。
- 会員の自力獲得案件へ、役務なしの負担を課すこと。
- 辞退による称号、案件配分、会員資格上の不利益。
- Case同意をKnowledge・AI利用の同意へ流用すること。
- COIの隠蔽、自己承認、顧客情報の目的外利用。
- 未回収制作、案件間の赤字相殺、将来価値による赤字正当化。
- ハラスメント、差別、報復、競合・守秘情報の漏洩。

違反の疑いがある場合は、新規受付・公開・二次利用を止め、顧客と提供者の保護を優先する。事実確認、影響評価、是正、再発防止、必要な通知を行い、処分は権限者がCOIを除外して判断する。

## データ・セキュリティ

- 必要最小限のデータのみ収集する。
- 保存先、閲覧権限、保持期限、削除方法を定める。
- 個人情報、契約、COI、非公開成果は役割ベースでアクセス制御する。
- AI学習、RAG、検索、評価への利用は独立した許諾を必要とする。
- インシデント時は利用・公開を停止し、影響範囲と通知要否を確認する。

## 改定

改定案には、変更理由、影響対象、既存契約への影響、移行方法、承認者を記録する。不利益変更は契約・規約・定款と必要な同意手続を法務確認する。重要な制度決定はGraph SSOTへdecisionとして登録する。

この文書の改定だけで契約変更、役職任命、外部公開、課金を実行したものとは扱わない。
