## 診断項目

### 1. 業務が見えているか

- [ ] その業務が、誰にどれだけ偏っているか分かる
- [ ] 作業の開始から完了までの流れを説明できる
- [ ] 繁忙期と閑散期で、業務量がどう変わるか分かる
- [ ] 割り込みや確認待ちがどこで起きるか分かる

### 2. 記録と最新版が残っているか

- [ ] 会話・会議・現場対応の記録が残っている
- [ ] 最新版の資料・ファイルの置き場が決まっている
- [ ] 過去の判断や対応履歴を後から確認できる
- [ ] 「言った・言わない」を避ける証拠が残る

### 3. 判断基準が人に閉じていないか

- [ ] ベテランが休んでも、同じ判断に近づける材料がある
- [ ] 例外対応の基準が言語化されている
- [ ] 顧客・社員・現場への確認事項が整理されている
- [ ] 最終判断者と承認フローが明確になっている

### 4. AIに任せる候補があるか

- [ ] 下書き、要約、分類、チェックリスト化できる作業がある
- [ ] 期限管理やリマインドをAIに任せたい作業がある
- [ ] 繰り返し発生し、毎回似た確認をしている作業がある
- [ ] まず1週間だけ記録を取れば、AI化の候補を選べそう

### 5. ロボット導入につながる作業分解ができるか（ロボット導入を検討する場合のみ）

- [ ] 定型・反復・記録可能な作業を切り出せる
- [ ] 例外、復旧、品質判断がどこで必要か分かる
- [ ] 人間が担うべき関係性・謝罪・合意形成を分けられる
- [ ] ロボットを買う前に、業務条件を説明できる

## 判定

### A. AI活用の基礎診断（1〜4の合計 / 16点）

- 0〜5点: まずは業務棚卸しから。AIツール選びの前に、仕事の流れと記録の置き場を整える段階です。
- 6〜11点: 1業務PoCに進めます。1週間の記録を取り、下書き・要約・期限管理から試すのが現実的です。
- 12〜16点: AI運用設計に進めます。人間の判断とAIの実行範囲を分け、継続運用のルールづくりに進めます。

### B. ロボット導入適性（5のみの合計 / 4点）

- 0〜1点: まだロボット導入を急がず、業務条件・例外・品質判断を整理する段階です。
- 2〜3点: ロボット導入の候補業務を1つに絞り、現場条件と例外対応を確認する段階です。
- 4点: ロボット導入の相談に進めます。AIで業務を見える化したうえで、機器・運用・人の役割分担を検討できます。

ロボットはオプションです。Aの点数が低くても、Bだけ高い場合は「現場作業の分解」から相談できます。Aが高くBが低い場合は、まずAIによる記録・判断支援から始めるのが自然です。
