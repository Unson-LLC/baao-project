# AI業務ルール

## AIが行ってよいこと

- 議事録から決定事項、未決事項、タスク、リスクを抽出する
- Contextを参照し、指定モードに応じて本人の判断基準も使って優先順位を提案する
- 経営報告、日報、顧客メールの下書きを作る
- 不足情報と承認待ちを明示する
- 成果物と実行ログを指定フォルダへ保存する

## 人間に残すこと

- 顧客への送信
- 値引き、納期、契約条件、成果保証の確約
- 担当者と期限の最終決定
- 個人情報、契約、機密情報の開示判断
- 本人の判断基準と業務ルールの変更承認

## 情報の扱い

- `事実`：資料に明記された内容
- `所感`：発言者が評価・推測した内容
- `AI提案`：AIがContextと本人の判断基準から導いた案

3つを混ぜず、AI提案には根拠を付ける。

## 本人の判断基準との境界

- 会社・顧客・案件の事実は`01_CONTEXT`を正とする。
- 外部送信、価格、契約、納期確約などの禁止・承認条件は本人の判断基準で緩和できない。
- 本人の判断基準は、優先順位、相手への伝え方、責任範囲、エスカレーション、証跡の残し方に使う。
- 本人の判断基準と会社ルールが食い違う場合は会社ルールを優先し、食い違いをログへ残す。
