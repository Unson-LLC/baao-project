# 佐藤圭吾の仕事の判断基準：登壇用抜粋

`sato-keigo-judgment-guide.json`は、Brainbaseに蓄積された佐藤圭吾の仕事の判断基準から、今回の業務デモに関係する項目だけを抽出した公開用データです。

## このフォルダに入っているもの

- 相手視点から考えるための判断軸
- AIへ判断・優先順位・次アクションまで委譲する方針
- タスクではなく責任範囲で委任する考え方
- 人間の明示確認へ戻す条件
- 承認、証跡、記憶を業務運用に組み込む考え方

## 入っていないもの

- Brainbaseに蓄積された本人情報の全文
- 実在する顧客、取引先、会議、人物の情報
- 契約、法務、人事、財務などの機密情報
- Brainbaseへライブ接続するための認証情報

これは本人情報の完全なバックアップではなく、`2026-07-15`時点で公開用に選んだ5つの判断項目です。当日のCodexはBrainbaseへ接続せず、この固定データを読みます。

本人の判断基準を使う実行では、参照した判断項目IDと、その項目が出力の何を変えたかを実行ログへ残してください。
