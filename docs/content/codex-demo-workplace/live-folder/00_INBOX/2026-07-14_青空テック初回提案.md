- 先方参加者：開発本部長 加藤翔太、情報システム室 山本香織
- 形式：青空テック本社での対面

## 1. 先方の現状

- 社員数は約380名、ITサポート専任は3名。
- 社内ヘルプデスクへの問い合わせが月800件を超えている。

- 2026年9月1日の組織改編までに、問い合わせ削減の成果を見せたい。

- 標準導入期間は8週間と説明した。
- 定型問い合わせのうち、まず30〜40%の削減を現実的な初期目標として提示した。

- 先方から、8月25日までの先行稼働と、ナレッジ整理の代行範囲を7月17日までに示してほしいと依頼された。
