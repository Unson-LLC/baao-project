# 株式会社ミナトクラウド 営業本部 AI業務フォルダ

このフォルダは、営業本部長の仕事をCodexへ委譲するための架空の業務環境です。

## フォルダの役割

| フォルダ | 内容 |
|---|---|
| `00_INBOX` | 新しく届いた議事録や依頼 |
| `01_CONTEXT` | 会社、顧客、案件についての事実 |
| `02_本人の判断基準` | Brainbaseに蓄積された佐藤圭吾の仕事の判断基準（公開用抜粋） |
| `03_RULES` | AIの権限、禁止事項、成果物の完成条件 |
| `04_OUTPUT` | Codexが作成する成果物 |
| `05_LOG` | 実行記録、参照情報、未確認事項 |
| `06_PROMPTS` | 手動実演とAutomation用の依頼文 |

会社名、人名、顧客名、案件名、金額はすべて架空です。`02_本人の判断基準`だけは、Brainbaseに蓄積された佐藤圭吾の仕事の判断基準から、実在顧客・会議・人物情報を除いて公開用に抜粋したものです。

## 比較実行

1. `06_PROMPTS/01_会社ルールのみ.md`で会社ルールだけの出力を作る。
2. `06_PROMPTS/02_本人の判断基準あり.md`で佐藤圭吾の判断基準を加えた出力を作る。
3. `04_OUTPUT`と`05_LOG`の2つのrunを比較する。

両方とも外部送信や未承認の確約は禁止です。比較するのは、相手視点、優先順位、責任境界、次アクション、証跡の質です。
