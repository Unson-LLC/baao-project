# Codexセミナーデモ制作正本

2026年7月15日「AIを質問相手で終わらせない」セミナー用の業務環境です。会社・顧客・案件・人物は架空ですが、AIの判断にはBrainbaseに蓄積された佐藤圭吾の仕事の判断基準から作った公開用抜粋を使います。

## 構成

- `live-folder/`: 当日Codexで開く業務フォルダの正本
- `PRESENTER_GUIDE.md`: 登壇者向けの実演手順と確認ポイント
- `SOURCE_AUDIT_PRIVATE.md`: 本人の判断基準の公開用抜粋に関する内部監査メモ。当日フォルダへコピーしない

当日は`live-folder/`の中身だけを、Desktopの`Codexデモ_架空商事/`へコピーして使います。Brainbaseへのライブ接続や認証情報は不要です。
