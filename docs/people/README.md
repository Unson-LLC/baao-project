# People｜会員・役職・活動履歴

- 更新日: 2026-07-17
- 現行正本: [`../internal/OPERATIONS_HANDBOOK.md`](../internal/OPERATIONS_HANDBOOK.md)
- 旧制度: [`archive/PEOPLE_POLICY_V1_LEGACY.md`](archive/PEOPLE_POLICY_V1_LEGACY.md)

BAAOの会員・役職は、貢献量を競わせるための序列ではない。顧客、会員、社会に対して、誰が何を判断し、どの品質と責任を引き受けるかを明確にする役割である。

## 基本原則

1. 会員資格、役職、案件実績を分ける。
2. 役職は権限、責任範囲、任期、任命根拠を伴う。
3. 活動履歴は証跡として残すが、点数、ランキング、年次失効へ変換しない。
4. CaseやKnowledgeへの協力を、資格維持、昇格、案件配分の条件にしない。
5. 辞退、保留、撤回を理由に不利益を与えない。
6. 固定の報酬率や優先アサインを称号だけで保証しない。案件別SOWで役務、責任、採算に応じて決める。

## 区分

| 区分 | 意味 | 必須記録 |
|---|---|---|
| Member | BAAOとの会員関係 | 会員主体、開始日、状態、適用規約 |
| Fellow | 専門家として登録された会員 | 専門領域、審査根拠、活動可能範囲 |
| Senior Fellow | 特定領域の品質レビューを担える専門家 | 審査根拠、責任範囲、COI、任期 |
| Field Director | 特定Fieldで委任された判断を担う責任者 | 権限範囲、A責任、任期、代替承認者 |
| Council / Governance role | 制度・ガバナンス上の決定を担う役職 | 任命権者、議決範囲、任期、COI |

雅称は対外表現であり、法的な権限、資格、契約主体を示すものではない。肩書きだけでBAAOの品質保証や案件責任を示してはならない。

## Appointment Record

公式役職を外部表示する場合は、Graph SSOTまたは承認済み役職台帳に次を持つ。

- 本人の正規表記と公開同意。
- 会員主体と役職名。
- 権限・責任範囲。
- 任命権者と任命根拠。
- 開始日、終了日、状態。
- COIと代替承認者。
- 公開可能な専門領域と検証URL。

検証可能な台帳がない役職、サンプルの任命番号、未確認の経歴は公開しない。任期終了は事実として表示するが、活動件数の不足だけで自動失効させない。

## Activity Ledger

活動は次の構造で記録する。

| 項目 | 内容 |
|---|---|
| Activity | 案件、監修、登壇、執筆、レビュー、コミュニティ支援など |
| Role | 本人が実際に担った役割 |
| Evidence | 契約、成果物、議事録、顧客確認、公開URL |
| Quality | 成果、再現性、納期、顧客・共同提供者のフィードバック |
| Rights | 公開、編集、配信、AI利用の許諾 |
| Return | 報酬、案件機会、配信、クレジットなどBAAOが返した価値 |
| COI | 判断に影響し得る関係と処理 |

履歴は本人の成長と第三者検証のために使う。件数や金額だけを順位化せず、失敗や撤回も学習として記録する。

## 役職審査

任命・更新では次を総合審査し、判断理由と承認者を残す。

- 専門品質と検証済み成果。
- 再現可能な方法と学習共有。
- 顧客・共同提供者への信頼性。
- 倫理、守秘、権利、COIへの対応。
- 協働、レビュー、異論を扱う力。
- 対象役職の責任を引き受ける意思と可用性。

自動昇格・自動降格は行わない。審査対象者に、根拠の確認、異議申立て、辞退の機会を与える。

## 案件アサイン

案件アサインは次の順で判断する。

1. 顧客課題と専門性の適合。
2. 利用可能時間と納期。
3. 顧客希望とチーム相性。
4. COI、守秘、競合制約。
5. 過去の品質と改善履歴。
6. 役務、責任、報酬、採算への合意。

称号の高さ、公開貢献の多さ、Knowledge提供への同意だけで優先しない。

## 公開プロフィール

公開するプロフィールは、Graph SSOTで本人、会員状態、役職、所属、専門領域を確認し、本人同意と必要な顧客許諾を得た情報に限る。

公開可能な項目:

- 氏名または合意した表示名。
- 現在有効な役職と責任範囲。
- 検証済みの専門領域。
- 許諾済みの実績と本人の役割。
- 公開可能な資料、登壇、連絡導線。

表示しない項目:

- 未確認の任命番号、所属、実績、成果数値。
- サンプル人物を実在会員に見せる表示。
- 活動ランキング、点数、点数連動の報酬・露出。
- 会員実績をBAAO受注または共同提供と誤認させる表現。

## 移行

旧People文書の名簿、任命番号、報酬、昇格条件は未検証のため現行扱いしない。公開名簿はGraph SSOTと本人同意を確認した人物から再構築する。確認不能は「0名」ではなく「未確認」と記録する。
