# NEC FY26 AI推進者向け実践プログラム 第3回

## 属人知を、組織とAIが使える知識へ

**日時**：2026年9月11日（金）15:00〜16:30
**対象**：AI活用を担当する方、各部門の管理者・リーダー
**形式**：講義75分＋質疑15分（第1・2回に参加していない方も参加可能）

### 開催趣旨

生成AI活用の焦点は、個人の作業支援から、人とAI Agentが役割を分担して業務を動かす段階へ移りつつあります。一方、会議、メール、チャット、文書に情報が残っていても、それだけではAIや組織が判断に使えるナレッジにはなりません。

本講義では、世界のAI活用の潮流を踏まえ、個人の経験や日々の記録を、出典と責任を保ったまま組織で利用できる知識へ変える考え方を解説します。文書検索にとどまらず、知識同士の関係、共通の意味、責任と権限、人による承認までを一つの業務設計として捉えます。

### 当日の予定

| 時間 | 内容 |
|---|---|
| 15:00〜15:10 | **世界の潮流――AI活用から、人とAgentによる業務運営へ**：個人の作業支援から、組織の仕事そのものを再設計する段階への変化 |
| 15:10〜15:25 | **属人知を組織知へ育てる**：日々の記録を候補化し、確認・承認を経て正本へ昇格させる流れ |
| 15:25〜15:45 | **RAG・知識グラフ・オントロジーの役割**：原文検索、知識同士の関係、個人の経験と組織知の境界、共通語彙と業務ルール |
| 15:45〜16:00 | **RACI・MCP・Agentによる安全な利用**：責任と権限、業務システムとの接続、人による承認・修正・停止 |
| 16:00〜16:10 | **全体像と実例**：記録が食い違うケースと、講師自身の実装例「Brainbase」 |
| 16:10〜16:15 | **自社で始めるための確認ポイントと今後の展開**：業務Agent、AI駆動PMO、AI駆動開発への応用 |
| 16:15〜16:30 | **質疑・意見交換** |

### 持ち帰っていただくこと

- 個人支援から、人とAgentによる業務運営へ移る世界の潮流と、そのために今から整えるべきこと
- 個人の経験を、そのまま全社ナレッジにしないための考え方
- RAGによる検索と、知識グラフによる関係把握の使い分け
- AIが参照・提案・実行する範囲をRACIと人の承認で制御する方法
- 自社で最初に対象とする業務を選び、AI駆動PMO等の次の展開へつなげるための確認ポイント

※本講義は特定製品の導入説明ではなく、企業でナレッジとAI Agentを扱う際の基本的な設計方法を解説するものです。
