# Statement of Work

**案件名**: グローウィン様向け AIガバナンス / 情報ガバナンス設計プロジェクト
**対象**: グローウィン・パートナーズ株式会社
**作成日**: 2026年6月25日
**作成**: BAAO / Unson
**ステータス**: 叩き台。契約当事者、開始日、対象データ、体制、支払条件は協議のうえ確定する。

---

## 1. 目的

本SoWは、グローウィン様の社内AI活用を進めるにあたり、AI時代の情報ガバナンス、データ権限、AI利用ルール、人間レビュー、外部送信基準、コミュニケーションプラン、会議体設計、会社運営案を設計する初期プロジェクトの作業範囲を定義する。

本プロジェクトは、一般的なAI利用規程の作成ではなく、グローウィン様の実際の会議体、業務ログ、利用SaaS、組織権限、顧客情報の扱いを踏まえ、社内実証と将来的なクライアント向けサービス化の両方に使える運用型のガバナンスを作ることを目的とする。

### 1.1 期待効果 / ROI

本プロジェクトの価値は、規程を作ることではなく、情報の流れと会社運営をAI前提で再設計することにある。

| 期待効果 | ROIの見方 |
|---|---|
| 情報の流れが整理される | 必要な情報が必要な人とAIに届き、議事録探索、資料作成、社内確認、二重説明の時間を減らす |
| AI活用が安全に速くなる | 使ってよい情報、使ってよいAI、レビューが必要な場面が明確になり、情報漏えい/誤送信を抑えながらAI導入を進められる |
| 会社運営の型が外販資産になる | 会議体、コミュニケーション、意思決定、AIレビューの型を作り、社内実証をクライアント向けサービスに転用しやすくする |

## 2. 前提

本SoWは、以下の前提に基づく。

| 区分 | 前提 |
|---|---|
| プロジェクト期間 | 契約締結日から3ヶ月を基本とする |
| 進め方 | 議事録/業務ログ等の分析と、グローウィン様側のレビュー/意思決定を組み合わせて進める |
| 基本体制 | グローウィン様側から、社内業務理解/調整を担うメンバー1名をアサインいただく |
| 対象データ | 組織図、部門ミッション、会議体、コミュニケーションチャネル、利用SaaS、既存情報管理ルール、議事録、業務ログ、AI利用状況等 |
| データ取扱い | 対象データ、アクセス権限、保存期間、削除手順はキックオフ時に確認し、必要に応じて別紙で定義する |
| 法務判断 | 法令適合性の最終判断、規程の法的レビュー、個別法務助言はグローウィン様または専門家の責任範囲とする |

初回の議事録/業務ログ分析の開始時期、対象データの取得可否、グローウィン様側のレビュー速度によっては、全体完了まで4〜5ヶ月に延長する可能性がある。

## 3. 作業範囲

### 3.1 対象範囲

BAAO / Unsonは、以下を実施する。

| 領域 | 内容 |
|---|---|
| 現状把握 | 組織図、部門ミッション、主要業務、利用SaaS、既存情報管理ルール、AI利用状況の整理 |
| 議事録/業務ログ分析 | Google Meet等の議事録、会議メモ、業務ログをもとに、会議体、情報利用、意思決定、部門間連携の論点を整理 |
| 情報カテゴリ設計 | 公開情報、社内一般情報、部門限定情報、顧客情報、個人情報、財務/経営機密、法務/契約情報、AI生成物等の分類 |
| AI利用レベル設計 | L0〜L4等の利用レベル、対象者、許可されるAI利用、制限事項、権限付与/剥奪ルールの設計 |
| SaaS/AI接続方針 | Google Workspace、CRM、ATS、会計、人事給与等とAIツールを接続する場合の確認観点整理 |
| レビュー/外部送信基準 | 顧客向け資料、社内判断資料、人事/財務/法務領域、経営判断における人間レビュー点の整理 |
| コミュニケーションプラン設計 | AI要約、会議ログ、タスク、意思決定事項をどのチャネルに流すかの初期設計 |
| 会議体/意思決定設計 | 経営会議、部門会議、プロジェクト会議、AI推進会議等の入力/出力/参加者/頻度/決定事項の整理 |
| 会社運営案 | 情報収集、論点整理、判断、実行、振り返りが回る運営サイクルの初期案作成 |
| 台帳/評価テンプレート | AI利用台帳、AIリスク/影響評価、AIツール/ベンダーチェックリストの作成 |
| インシデント対応 | 情報漏えい、誤送信、権限外参照、不適切出力等の初期対応フロー整理 |
| 実装方針整理 | 必要に応じて、AIツールやMCP権限ツール等への組み込み方針を整理 |
| 外販化仮説 | グローウィン様のクライアント向け診断/設計メニューに転用する際の初期仮説を整理 |

### 3.2 対象外

以下は本SoWの対象外とする。必要な場合は、別途見積または追加SoWで定義する。

| 対象外 | 内容 |
|---|---|
| 法務意見書 | 法令適合性の保証、個別法務助言、規程文言の最終法的レビュー |
| 本番システム開発 | MCP権限ツール、社内AI基盤、データ統合基盤等の本番実装 |
| 全社展開運用 | 全社員向け研修、全社オンボーディング、問い合わせ窓口の常設運用 |
| データ移行/統合 | DWH、データレイク、ID管理基盤、既存SaaS権限の全面再構築 |
| 第三者費用 | AIツール利用料、SaaS追加費用、外部専門家費用、出張交通費 |
| 高機微データ処理 | 個人情報、給与、評価、採用候補者、契約/紛争情報等の詳細処理。ただし、利用可否と管理方針の設計は対象に含む |
| 組織再編/人事制度変更 | 組織改編、人事評価制度、職務権限規程の変更決定および実行 |
| 常設運用代行 | 社内広報、問い合わせ窓口、会議運営、PMO、全社展開後の定常運用 |
| レベニューシェア契約 | 外販時の収益分配、販売代理、継続顧問契約等の商流設計 |

## 6. 体制 / RACI

| 役割 | 担当 | RACI | 内容 |
|---|---|---|---|
| プロジェクト責任者 | グローウィン様責任者 | A | 目的、対象範囲、意思決定、成果物承認 |
| 社内業務理解/調整 | グローウィン様アサインメンバー | R | 会議体、業務実態、人間関係、例外運用、コミュニケーション導線の補足、部門調整 |
| AI/データ接続確認 | グローウィン様AI推進/情報管理担当 | R/C | SaaS、AIツール、データ権限、ログ、セキュリティ確認 |
| 全体設計/方針整理 | BAAO / Unson | A/R | AI・データガバナンス設計、論点整理、成果物レビュー |
| 分析/実装支援 | Unson支援メンバー | R | 議事録/業務ログ分析、テンプレート作成、会議体/会社運営案作成、AIツール/MCP等の実装方針整理 |
| 専門レビュー | グローウィン様法務/情シス/人事等 | C | 個別領域の妥当性確認、制約条件の提示 |
| 関係部門 | グローウィン様各部門 | I/C | 必要に応じたヒアリング、確認、フィードバック |

RACIの定義は、A=最終責任、R=実行責任、C=相談先、I=共有先とする。

## 10. 機密保持 / データ取扱い

BAAO / Unsonは、本プロジェクトで受領する資料、議事録、業務ログ、顧客情報、個人情報、AI利用情報を、本プロジェクトの目的に必要な範囲でのみ利用する。

| 項目 | 方針 |
|---|---|
| 利用目的 | AIガバナンス設計、情報権限整理、業務実態分析、成果物作成 |
| アクセス者 | BAAO / Unsonの本プロジェクト担当者および双方で合意した支援メンバーに限定する |
| 外部共有 | グローウィン様の事前承諾なく第三者へ共有しない |
| AI利用 | 外部AIツール/APIに入力するデータ範囲、マスキング要否、保存/学習設定を事前に確認する |
| 保管期間 | 原則としてプロジェクト期間中および終了後30日以内とし、以後は削除または返却方針を双方で確認する |
| 匿名化 | 外販化仮説や公開可能な事例化を行う場合は、個社名、個人名、機密情報を除いた匿名/抽象化情報のみを扱う |

公開事例、営業資料、記事、セミナー等で本プロジェクト内容を利用する場合は、グローウィン様の事前承諾を得る。

## 11. 変更管理

以下に該当する場合は、スコープ変更として扱い、追加見積または期間変更を協議する。

| 変更対象 | 例 |
|---|---|
| 対象部門の拡大 | 初期対象外の部門/子会社/海外拠点を追加する |
| 対象データの拡大 | 大量の追加ログ、個人情報、給与/評価、契約/法務情報を詳細分析する |
| 会議体/会社運営設計の拡大 | 初期設計案を超えて、全社会議体の再編、部門横断PMO、運営代行まで求める |
| 成果物の追加 | 全社員向け研修資料、正式規程、システム要件定義書、本番実装仕様書を追加する |
| 実装作業の追加 | AIツール、MCP権限ツール、ダッシュボード、データ基盤を実装する |
| レビュー回数の追加 | 合意済み回数を超える大幅な再設計、追加レビューを行う |
| 期間延長 | グローウィン様側レビュー、データ提供、社内調整の遅延により期間を延長する |

スコープ変更は、メール、議事録、変更合意書等、双方が確認可能な書面で合意する。
