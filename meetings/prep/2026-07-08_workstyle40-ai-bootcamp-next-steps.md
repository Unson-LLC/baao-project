## 2. 資料から読める商品設計

### 全体像

働き方4.0は、以下の3ステップで設計されている。

| ステップ | 内容 | BAAO視点の意味 |
|---|---|---|
| 1. 診断 | 業務、契約、固定費構造、PCログ、SaaS利用状況などを可視化 | AI導入前の業務棚卸し。ここは社労士・コンサル主導だが、SaaS/MCP接続やデータ設計でBAAOが入れる |
| 2. AI前提で再設計 | AIに任せる仕事、人が価値を出す仕事、外部活用する仕事に分ける | BAAOの中核。業務分解、AI化候補、実装難易度、Claude/API活用設計 |
| 3. 契約と実施を最適化 | 評価制度、契約形態、業務委託、助成金・補助金、実装伴走へ接続 | 労務・契約判断は社労士/弁護士側。BAAOはAI実装・開発管理・ダッシュボードに限定 |

### ブートキャンプ

AI経営×クエスト型ブートキャンプは、5時間の経営者・幹部向けワークショップ。説明型研修ではなく、Claude Code、OpenAI API、ChatGPT、Gemini等を使い、前半は反復AIドリル、後半は経営シミュレーションでAIあり/なしの差を体感させる構成。

持ち帰り成果物は、Claude Code稼働環境一式、AI経営チーム設計図、経営会議スコアレポート、90日アクションプラン、月次1on1伴走など。議事録で言及されていた「Claude Code導入までの講座」に近いが、資料上はより経営者向けのAI意思決定ブートキャンプとして設計されている。

### 評価・再配置

評価再配置資料は、業務を「深度」「種類」「成果」の3軸で評価し、正社員・プロ人材・AIへ再配分する考え方。さらに評価制度のAI化、評価根拠の収集、評価シミュレーター、労働者性7軸チェック、偽装請負リスク、フリーランス新法までつないでいる。

ここは非常に強いが、BAAOが前面に出すと労務・人事判断の責任境界が曖昧になる。BAAOは「AIによる事実整理・業務分解・実装支援」まで、最終判断と労務適法性は社労士/弁護士レビュー必須、という線引きが必要。

### 価格帯

OCRベースで確認できた範囲では、以下の設計。

| 区分 | 価格・条件 |
|---|---|
| 診断 | 無料/10万円/30万円相当。診断費は自己負担、助成対象外 |
| 評価・再配置コンサル | 50万円、150万円、400万円、800万円の段階プラン |
| 研修費 | AI改善カテゴリとして別積み。人材開発支援助成金の対象になり得る設計 |
| 開発・ツール費 | 300万円相当の記載あり。省力化投資補助金などと接続 |
| 成功報酬 | 下がった社会保険料の10%相当という記載あり。ただし助成金とは連動しない設計 |

BAAOとして最も注意すべきは、成功報酬が「社会保険料削減」に連動して見える点。ここをそのままBAAO名義で受けると、「社員削減で儲ける」印象と労務リスクが強い。BAAO側の報酬は、研修、AI実装設計、開発管理、AIダッシュボード、業務改善伴走の固定/準委任/開発費に寄せるべき。

## 3. BAAOの関与方針案

### 引き受ける

- AIブートキャンプの技術設計・講師・ファシリテーション
- Claude Code / OpenAI API / ChatGPT / Gemini の環境準備と教材化
- 業務分解ワーク、AI化候補の洗い出し、実装難易度評価
- 社内SaaS・議事録・ファイル・CRM等をClaude/MCPでつなぐ設計
- AI経営チーム、エージェント定義、実行コマンド、90日アクションプラン
- 実装フェーズの開発監督、NamedFox/金田さん等への開発連携
- 経営判断ダッシュボードや評価シミュレーターのプロトタイプ設計

### 引き受けない、または前面に出さない

- 社員削減そのものの提案
- 社会保険料削減を目的化した成果報酬
- 労働者性、偽装請負、フリーランス新法、就業規則、不利益変更の最終判断
- 助成金・補助金の採択保証、受給保証
- PCログ等の監視運用を本人周知・権限設計なしで進めること

### 外向き表現

避ける表現:
- AIで社員を削減する
- 社保を下げる
- 外注化で固定費を削る

使う表現:
- 仕事を分解し、人・AI・外部パートナーの最適配置を設計する
- 人が価値を出せる仕事へ戻す
- AIは判断材料を整理し、最終判断は経営者と専門家が行う
- 労務・契約・評価制度は専門家レビューを前提に段階導入する
