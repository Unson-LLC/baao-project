# NEC FY26 AI推進者向け実践プログラム 第1回 ミニワークシート

**用途**: 第1回のミニワークで書き始め、第2回までの宿題提出にも使う。
**入力ファイル**: `2026-06-12_nec-session1-miniwork-sheet.csv`

---

## ミニワーク中にまず埋める欄

7分のミニワークでは、すべて埋めなくてよい。まず以下を入力する。

| 優先 | 入力欄 | 書くこと |
|---:|---|---|
| 1 | 記入者/グループ | グループ名、または記入者名 |
| 2 | 上期テーマ | 自グループで進めたいAI活用テーマ |
| 3 | 対象業務カテゴリ | 問い合わせ対応、申請書/手順書チェック、ナレッジ収集など |
| 4 | 対象業務の説明 | どの業務を対象にするかを1文で書く |
| 5 | 現状の困りごと | 時間がかかる、品質がぶれる、探せない、属人化している等 |
| 6 | 現在の手順（5行以内） | 今、人がどの順番で作業しているか |
| 7 | AIに任せたい作業 | 分類、検索、要約、チェック、回答案作成、記録など |

---

## 宿題で追記する欄

ミニワーク後、第2回までに以下を追記する。

| 入力欄 | 書くこと |
|---|---|
| 月あたり件数 | 対象業務のおおよその発生件数 |
| 1件あたり所要時間 | 現在の平均処理時間 |
| 時間がかかる作業 | AIで軽くしたい作業 |
| 品質がぶれる判断 | 人によって判断が変わりやすい箇所 |
| 毎回探している情報 | FAQ、手順書、過去対応履歴、規程など |
| 入力データ | AIに渡せそうなデータ |
| 人が判断すること | AIに任せず、人が最終確認すること |
| 利用候補環境 | NGS、RAG、M365 Copilot、NotebookLMなど |
| 扱えない/注意すべき情報 | 最高機密、極秘、顧客固有情報、個人情報など |
| 成果指標 | 工数、対応時間、差し戻し率、検索時間、品質など |
| Before / After | 現状と目指す姿 |
| 次回聞きたいこと | 第2回で相談したい論点 |

---

## 進行時の声かけ

今日の段階では、きれいな改善案にする必要はありません。
まず「どの業務をAIで扱いたいのか」「人の作業のどこが重いのか」「AIに任せるなら何を任せたいのか」まで書ければ十分です。

第2回では、提出されたシートのうち2〜3件を例に、問い合わせ対応や申請書チェックの具体的な分解と精度の上げ方を扱います。
